# Iris Dataset Analysis & Machine Learning

An end-to-end Machine Learning project focused on Exploratory Data Analysis (EDA), data visualization, and classification using the famous Iris flower dataset.

## 📌 Project Overview

The Iris Dataset Analysis project explores the characteristics of three Iris flower species using Python. It applies data analysis and visualization techniques to understand relationships between flower measurements and uses Machine Learning algorithms to classify flower species.

The project demonstrates a complete beginner-level Machine Learning workflow, from loading and exploring data to training and evaluating classification models.

## 🎯 Project Objectives

- Understand and explore the Iris dataset.
- Perform Exploratory Data Analysis (EDA).
- Analyze patterns and relationships between numerical features.
- Visualize data using Python visualization libraries.
- Build classification models using Machine Learning.
- Evaluate and compare model performance.

## 📊 Dataset Description

The project uses the Iris dataset, which contains 150 observations, representing three flower species.

### Dataset Features:

Feature| Description
Sepal Length| Length of the sepal
Sepal Width| Width of the sepal
Petal Length| Length of the petal
Petal Width| Width of the petal
Species| Iris flower category

### Target Classes:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

Each species contains 50 observations.

## 🔍 Project Workflow

1. Data Loading: Import the Iris dataset from the CSV file.
2. Data Exploration: Examine dataset structure, features, and species distribution.
3. Data Visualization: Create visualizations to understand feature distributions and relationships.
4. Data Preparation: Separate input features and target labels, then split the dataset into training and testing sets.
5. Model Training: Train classification models using the training data.
6. Model Evaluation: Evaluate predictions using accuracy, classification reports, and confusion matrices.

## 🤖 Machine Learning Models

Two classification algorithms are implemented:

1. Logistic Regression

A supervised Machine Learning algorithm used to classify Iris flowers into their respective species.

2. K-Nearest Neighbors (KNN)

A classification algorithm that predicts the species based on the nearest data points.

## 📈 Model Evaluation

The models are evaluated using:

- Accuracy Score
- Classification Report
- Confusion Matrix
- Model Performance Comparison

These evaluation methods help assess how accurately each model predicts the flower species.
